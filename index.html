一、基础认知

什么是牙周炎？

牙周炎是由牙菌斑细菌引发的慢性炎症，破坏牙龈、牙周膜和牙槽骨，是成年人失牙的首要原因。它通常始于可逆的牙龈炎（红肿、出血），若未干预，则发展为不可逆的牙周炎，出现牙周袋和牙槽骨吸收。

牙龈炎 vs 牙周炎

牙龈出血通常是牙龈炎的典型表现，此时炎症仅限于牙龈软组织，通过清洁可完全逆转。若长期忽视，炎症会向深层发展，破坏牙槽骨，这才演变为不可逆的牙周炎。能止住的出血多是牙龈炎，伴随牙齿松动或牙龈萎缩的出血，往往已是牙周炎。

牙菌斑与牙结石

牙菌斑是口腔细菌在牙齿表面不断沉积形成的无色黏性生物膜，通常在刷牙后数小时内即可重新生成。若牙菌斑未被及时清除，其中的矿物质（主要是唾液中的钙、磷）会逐渐沉积、矿化，在24至72小时内开始形成坚硬的牙结石。牙结石一旦形成，无法通过刷牙去除，只能通过专业洁治（洗牙）清除。

二、口腔卫生行为

巴氏刷牙法

将牙刷刷毛与牙龈呈45度角，对准牙齿与牙龈的交界处，以小幅水平震颤的方式轻轻刷动，每次覆盖2-3颗牙。这种震颤动作主要用于清除牙龈沟内的牙菌斑，而非大幅拉锯式横刷，以避免损伤牙龈和牙齿颈部。

牙线使用

持牙线棒柄部，将牙线对准牙缝，以轻柔的拉锯式动作滑入牙龈沟底，然后将牙线紧贴一侧牙面，从沟底向咬合面方向提拉刮除菌斑。每清洁一个牙缝后，用纸巾擦净或冲洗牙线棒，避免将菌斑带入下一个牙缝。

冲牙器使用

冲牙器利用高压脉冲水流冲走牙缝和牙龈沟内的食物残渣及松散菌斑，适合作为刷牙和牙线的辅助工具。使用时将喷头垂直于牙面，沿牙龈边缘缓慢移动，每颗牙停留1-2秒。注意冲牙器无法有效清除紧贴牙面的成熟菌斑，不能替代传统牙线。

三、风险因素与症状

早期症状（容易被忽视）

牙周炎早期症状通常不明显且无痛，主要表现为刷牙或咬硬物时牙龈出血、口腔异味，以及牙龈边缘红肿。用手指沿牙龈边缘轻轻推压，可能挤出少量渗液。若出现牙龈与牙齿分离形成"假性牙周袋"，或单颗牙咀嚼无力，提示已从牙龈炎进展为早期牙周炎。

牙龈肿胀 牙龈出血 牙龈疼痛 牙齿松动 咀嚼无力 口臭 牙龈退缩 口干症

牙龈萎缩与牙齿松动原因

最常见原因是牙周炎——牙菌斑堆积导致牙槽骨持续吸收，失去骨骼包裹的牙龈随之退缩，牙齿也因支持组织减少而松动。其他原因包括刷牙用力过猛造成的机械性牙龈损伤、牙齿咬合创伤，以及随年龄增长发生的生理性骨量减少。

口臭与牙周炎

牙周炎是导致口臭的常见器质性原因之一。牙周袋内的厌氧菌分解含硫氨基酸，产生挥发性硫化物（如硫化氢、甲硫醇），直接发出腐败性气味。这种口臭无法通过刷牙、漱口水或嚼口香糖根除，只有通过牙周治疗清除菌斑和牙石后才能有效控制。

四、治疗与预防

洗牙（洁治）

洗牙主要分为两个步骤：先用超声波洁治器震碎并去除牙石和菌斑，再用手用器械进行精细刮治，最后进行抛光以减少菌斑再次附着。整个过程通常伴有轻微酸胀感，但不会损伤牙齿或导致牙缝变大——牙缝显露恰恰是因为原有的牙石被清除后，已经存在的牙龈萎缩暴露出来。定期洗牙（每年1-2次）是预防和治疗牙周炎的基础措施。

龈下刮治

使用精细的手用器械或超声波器械，伸入牙龈下方的牙周袋内，将附着在牙根面上的牙石和菌斑彻底清除的操作。该治疗通常在局部麻醉下进行，以消除炎症根源，促进牙龈与牙根面重新贴合。与常规洗牙相比，龈下刮治针对的是牙龈下方不可见的病变，是治疗牙周炎的核心手段。

牙周炎手术

主要包括翻瓣术和再生性手术，是在基础治疗无法控制深牙周袋时进行的介入方式。翻瓣术是将牙龈翻开，在直视下彻底清除根面菌斑和牙石，并修整病变组织；再生性手术则在清除病灶后植入骨粉或生物材料，引导被破坏的牙槽骨再生。

五、大学生高发原因

为什么大学生容易得牙周炎？

作息不规律：熬夜刷剧、打游戏导致免疫力下降，口腔自洁能力减弱。

饮食习惯：高糖饮料、外卖频繁，口腔环境恶化，为细菌繁殖提供温床。

忽视口腔卫生：懒得刷牙、不用牙线，菌斑堆积形成牙结石。

压力大：考试周焦虑引发磨牙、免疫力降低，加重牙周炎症。

错颌畸形：牙齿排列不齐导致清洁困难，局部菌斑堆积风险增加。

心理健康与口腔健康

焦虑、抑郁、长期精神压力是灼口综合征、复发性阿弗他溃疡、磨牙症等疾病的重要诱因。不良心理状态可抑制免疫功能，使牙周炎更易发生且难以控制。同时，口腔病痛（牙痛、牙龈肿痛、口臭等）也会引发焦虑、烦躁、失眠及抑郁情绪，形成恶性循环。

六、能否逆转？

🟢 早期牙龈炎 — 完全可以逆转

炎症仅限于牙龈软组织，未伤及深层组织。通过洗牙、正确刷牙、使用牙线可完全恢复，牙龈出血可完全停止。

🟡 轻度牙周炎 — 可控制，部分恢复

已有轻度牙槽骨吸收，但通过龈下刮治和良好口腔卫生维护，可以阻止病情进展，部分组织可修复。

🔴 中重度牙周炎 — 不可逆，需终身维护

牙槽骨已明显吸收，牙周袋形成。只能通过治疗控制炎症，无法完全治愈，需要定期复查维护，防止牙齿脱落。

关键提示：牙龈炎不松动，牙周炎牙齿会松动！早期发现是关键。

基础检查日

了解自己的口腔现状

✓ 记录是否有刷牙出血情况

✓ 购买软毛牙刷和含氟牙膏

2

正确刷牙法

学习巴氏刷牙法

✓ 牙刷45度角对准牙龈沟（牙齿与牙龈交界处）

✓ 小幅度水平颤动（2-3颗牙为一组），避免大幅横刷

✓ 每次刷牙至少2分钟，每天早晚各一次

✓ 刷毛尖端垂直清洁后牙咬合面凹槽

3

牙线初体验

清洁牙缝，去除邻面菌斑

✓ 购买牙线棒或卷状牙线

✓ 轻柔拉锯式滑入牙龈沟底，不要用力过猛

✓ 将牙线紧贴一侧牙面，从沟底向咬合面提拉刮除

✓ 每晚睡前使用一次，出血是正常的，坚持一周会改善

4

饮食调整日

减少糖分摄入

✓ 用白开水代替含糖饮料，少喝奶茶

✓ 吃完零食后漱口，清除食物残渣

✓ 增加蔬菜水果摄入（纤维清洁牙齿）

✓ 避免睡前吃东西，减少夜间细菌繁殖

5

漱口水与冲牙器

辅助清洁工具

✓ 购买含氯己定或精油的漱口水（非必需，刷牙后使用）

✓ 含漱30秒，不要立即用清水漱口（保持药效）

✓ 冲牙器喷头垂直于牙面，沿牙龈边缘缓慢移动

✓ 注意：漱口水和冲牙器都不能替代刷牙和牙线

6

习惯巩固日

建立完整口腔护理流程

✓ 早：巴氏刷牙法2分钟

✓ 中：午饭后漱口

✓ 晚：刷牙2分钟 + 牙线 + 漱口水

✓ 设置手机提醒，坚持21天养成习惯

7

专业检查预约

定期洗牙，专业防护

✓ 搜索附近口腔医院/诊所

✓ 预约洗牙（龈上洁治），每年1-2次

✓ 如有出血、松动等症状，咨询是否需要龈下刮治
